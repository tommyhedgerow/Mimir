## 🔁 Session ritual — read this first

_How a session should run, in my own words. These are the standing defaults — read this block before anything else, and change any of them here when they do not fit._

1. **Create the session note immediately at the start** — `Learn/Sessions/YYYY-MM-DD Topic.md`, from the template — and **open it in Obsidian**:
   `obsidian://open?vault=<vault name>&file=<url-encoded vault-relative path>`
   (The note can be opened before it has any content, or created blank first.)
2. **Write into it as the session runs**, not at the end. Probe table, plan, nodes and checks fill in live — **I read there, not in chat**, because that is where diagrams render.
3. **A picture must fit the column and read in one look. Mermaid is not the default.** Strand maps are **SVG** — `Learn/Viz/<subject>-map.svg`, written by `Tools/vault-chart.mjs` from the map's `graph:` spine and the concept notes, sized to the reading column and embedded inline in the map note. Mermaid survives only in session plans, and only where the graph is genuinely a DAG rather than a chain. Verticality holds wherever a graph *is* drawn — **I scroll, I do not pan** — but **tall is a failure too**: if a picture needs scrolling it is too big, and the fix is fewer nodes or a different form, never a smaller font.
4. **Cost discipline — one bounded verifier call, not a battery.** A fact-check is cheap and expected: **batch the turn's claims into one `subagent_researcher` call**, or verify directly, or say plainly that a check did not run. Still ask first before starting a *round* of specialist subagents.
5. **Inline links in the prose of the note**, every proper noun, text, dynasty or person at first mention — see *How I like to be taught*. The Sources list is in addition to this, not instead of it.
6. **A verifier call that runs out of fetch budget is not a check that ran.** Batch *fewer* claims, or settle the load-bearing ones directly against the primary source — and where a check did not run, the note says so.
