# Review queue

> Open items first, oldest due date at the top. One line per concept. The rule: **retrieval, not re-reading** — and a miss means repair before rescheduling.
>
> Format: `- [ ] [[Concept]] — due YYYY-MM-DD — ask: <the question that proves it>`
> When reviewed: `- [x] [[Concept]] — reviewed YYYY-MM-DD — held / partial / missed — next YYYY-MM-DD`
>
> Intervals double on a clean retrieval (first review within a week, then ~2 weeks, ~1 month, ~2 months, ~4 months). On a miss, halve the gap and repair the concept note in the same session. Four clean retrievals and the concept is `established`; stop scheduling it and take it off this list, so the queue stays short enough to actually work.
