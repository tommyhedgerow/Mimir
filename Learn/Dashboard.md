# Dashboard

> My own state, read out of the notes rather than retyped. Every table below is a live view over the frontmatter of `Learn/` — nothing here is maintained by hand, so nothing here can quietly disagree with the notes it comes from.
>
> The views are defined in `Learn/Dashboard.base`. To add or change one, open that file (or use the view menu in any table below).

## What is due

![[Dashboard.base#Due]]

_Days counts down to the due date; a negative number is overdue._

## What I hold, and how solidly

![[Dashboard.base#Concepts]]

_Grouped by `status`. **`fragile` is a flag, not a status** — a fragile concept is drawn in red on its strand map, and it means: retrieve this cold before building anything on top of it. Nothing is flagged yet, because nothing has been taught yet._

## The strands

![[Dashboard.base#Strands]]

_One line per strand: where it stands, what the frontier is, what is next. This is the map frontmatter, so it moves when the map moves. The table stays empty until the first subject has a map in `Learn/Maps/`._

## Sessions

![[Dashboard.base#Sessions]]

_`Probe %` is the share I got right in the bracketing probe. **A low score is a well-aimed probe, not a bad session** — an all-correct probe means the questions were too easy and the edge was never found._

## The retrieval log

![[Dashboard.base#Retrieval log]]

_Empty, and honestly so: nothing has been retrieved yet. It fills the moment `retrievals:` is written into a concept note after a review session — and it is the only table here that will ever show whether any of this is sticking._
