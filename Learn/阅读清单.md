# 📚 阅读清单

> 值得和会话一起读的书，按脉络分。规则：**每次会话至多一两本**，在写回时加上，为了书能承载而一节课承载不了的东西——一整片领域的质地，或者一个需要一百页而不是一个节点的论证。
>
> **只收已出版的虚构与非虚构** —— 不收论文，不收期刊。一本合适的胜过两本凑数的，而一节什么都没教会的课什么也不加。

## 链接是怎么来的

每一本进这份清单的书都先被核实为真实存在——作者、书名和首次出版年份——才被列出，而且它带一个已确认能打开到正确条目的链接。没有任何书是凭一个听起来对的书名就列上的。

**关于链接规则的一段说明，因为这个偏好无法照字面兑现。** 自然的诉求是：有精装零售链接就用它，没有就用 Goodreads。有两件事挡下了这条路：

- **Goodreads 会拦住自动核实** —— 它返回的是一个机器人挑战页而不是页面本身，所以一个 Goodreads 网址无法被确认能打开到正确的版本。一个无法核实的链接，正是这个库不做的事。
- **被点名的那家零售商 Brilliant Books 至少从 2026-09-17 起就已经不可用**：它的 TLS 证书**于 2026-04-07 到期**，而它自己的根网址返回 `403`。放在那里的链接会让读者迎面撞上一个安全警告。

所以链接指向 **Open Library** —— 免费、没有机器人墙，而且它的 `/works/…` 标识符是规范的，不会像商店网址那样烂掉。Open Library 没有收录某个作品时，链接是一个核实过的搜索页或出版社页面，并会说明这一点。**如果更喜欢，可以把其中任何一个换成 Bookshop.org 或 Goodreads 页面——条目的重点是书，不是店。**

**这立下的标准，以及它的理由：** 去解析一个标识符，而不是相信一个网址能打开。对某个图书信息页发一个普通请求，可以在背后是一张机器人验证页的情况下返回 `200`，所以点开看一眼什么也证明不了；标识符核查才能抓住一个指向空记录的链接，或者指向一本完全不同的书。**这是这个库关于「解析标识符而不是相信网址能打开」的常设论证。**

**每条都取同样的形状**，一行一条：

- **[*书名*](链接)** —— 作者（年份）。一行说明它加上了什么是一节课给不了的。

_还没有书，而这是规则本身，不是遗漏：一本书是在某次会话教了某样书能延伸的东西之后、在写回时加上的。一本合适的胜过两本凑数的。_

## 来源

- **核实方法。** 每个书名、作者和首次出版年份在列出之前都对着 [Open Library](https://openlibrary.org) 核实过，然后链接是**对着 Open Library 的作品 API 解析过的**，而不是仅仅点开看一眼。这个区别很要紧：对 Open Library 某个页面发一个普通请求会返回 `200`，背后却是一张*机器人验证*页，所以点开看一眼什么也证明不了。走一遍 API 才能抓住一个指向空白占位记录的标识符，或者指向**一本完全不同的书**的标识符。
- **这份清单上的每个链接都是一条真实的作品记录。** 它解析到一条有内容的 Open Library 作品，从来不是一个用来代替缺失作品记录的搜索页。Open Library 没有收录某本书时，这本书就干脆先不列——这是留给会话需要时去补的空缺，绝不是凭空造一个标识符的理由。
- **按规则排除的类别。** 不收学术论文，不收期刊文章，也不收野外手册和图鉴——那些是工具而不是读物，而一次鉴定会话会自己挑它的工具。
