# 🌱 学习 — 首页

> [English](🌱%20Learn%20Index.md) · **简体中文**

> 这是笔记库的前门。[我们如何学习](我们如何学习.md) 是方法；[学习者档案](学习者档案.md) 是你站在哪里；[学习清单](学习清单.md) 是你要去哪里；[[概览]] 是把这一切的现状直接从笔记里实时读出来。
>
> **常设格式：** 会话笔记在会话开始时创建并在 Obsidian 里打开，边讲边写。**一张图必须放得进阅读栏，并且一眼读完** —— 脉络图是生成在 `Learn/Viz/` 里的 SVG，不是 mermaid。

## 从这里开始

还没有讲过任何东西，所以这个库的大部分是刻意空着的。形状才是重点：填进去的是形状。

1. **在 DSH 里打开这个文件夹**，并为这次会话选择 **Mimir 导师** 预设。是这个组合让它成为导师而不是聊天机器人——预设带着方法（以技能的形式）、六个专家，以及关于核实事实和把内容写回笔记库的常设规则。仓库根目录的 `INSTALL.md` 讲了整个过程。
2. **说出你想学什么。**「教我板块构造。」「我想弄明白康德到底做了什么。」「讲讲菌根。」导师会探测你已经掌握了什么，提出一张依赖图，等你点头，然后一个节点一个节点地把这个主题搭起来。
3. **在 Obsidian 里跟着读。** 导师写的每样东西都作为笔记落进这个库，图就在文字所在的地方渲染。
4. **到期了就复习。** 要一次复习会话，它会走 [[复习队列]] ——先提取，答错就修，下一个日期由这次做得怎么样决定。

## 图谱

_`Learn/Maps/` 里每个脉络一条笔记，每条记录依赖顺序和当前前沿。你要求第一个学科时，第一条就出现了。_

_`Learn/Concepts/` 里的原子笔记，一条一个念头，用双链连成一张图。概念是知识本身；会话是获得它的记录。会话讲完一个节点，它们就填上一条。_

## 最近的会话

_`Learn/Sessions/` 里每次会话一条带日期的笔记，来自 `Templates/Session.md`。_

## 这个库怎么运作

- **会话**住在 `Learn/Sessions/`，每次一条带日期的笔记，来自 `Learn/Templates/` 里的模板（`Session`、`Concept`、`Map`）。
- **概念**住在 `Learn/Concepts/`，一条笔记一个念头，用双链连成图。
- **图谱**住在 `Learn/Maps/`，每个脉络一条，记录依赖顺序和当前前沿。
- **复习**住在 `Learn/Reviews/`。
- **来源**住在 `Learn/Sources/`；**图**住在 `Learn/Viz/`。
- **视图**住在 `Learn/Dashboard.base`，嵌在 [[概览]] 里——什么到期了、什么不稳固、每个脉络走到哪。它们读属性，所以不会和笔记脱节。
- 完成的工作会**发布**进第二个文库，一次一条笔记——见 `Tools/publish-to-library.sh`。

## 三个生成器

三个脚本做那些不能交给手去保持最新的活。在库根目录运行：

```sh
node Tools/vault-map.mjs        # 校验图谱和会话笔记里的主干
node Tools/vault-chart.mjs      # 从那些主干重画 Learn/Viz 里的每一张 SVG
node Tools/check-tokens.mjs     # 主题和图的调色板不一致时就失败
```

`vault-chart.mjs` 用系统的文字引擎量标签的宽度，而不是数字符，并且拒绝写出一张文字放不进方框的图。
