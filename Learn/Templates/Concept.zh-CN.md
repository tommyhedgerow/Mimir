## 🃏 Cards

_Anki 能从这条念头里装的，只有这些。*为什么它必须是这样* 那一节里的推导**绝不能**变成卡片——卡片把重建变成辨认，而 `reviewing` 技能明确说这比不复习更糟。这里该放的是事实形状的残余：一个名称、一个日期、一个特征，或这条笔记*我在哪里弄错了*所说的那句错话。收集：`node Tools/anki-cards.mjs --all`。_

_**一句要判断的话，或一个问题** —— `front :: back :: kind`（kind 可省：`trap`、`name`、`date`、`species`、`fact`）：_

- _那句错话，写得像真的一样？——它站得住吗？ :: **站不住** —— 它错在哪里，一两句话。_ :: trap

_**或者一张填空卡** —— 一句真话里挖掉一个词，写作 `{{c1::…}}`，kind 必填，中间可以放一条提醒（`句子 :: 提醒 :: kind`）：_

- _《埃帕纳戈格》成于 {{c1::886 年}}，扩大了牧首对查士丁尼立法的权力。_ :: date

_Anki 会为每个 `{{cN::}}` 生成一张卡，所以一句话里的名称和日期就是两张卡——而每个空都会出现在另一张卡的正面，这也是为什么一个空只该藏一件事。_
