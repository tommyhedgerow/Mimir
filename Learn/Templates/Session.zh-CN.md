## 🃏 Cards

_Anki 能装的，只有这些。**两种形状，由句子决定是哪一种。** 收集：`node Tools/anki-cards.mjs --all`。_

_**一个问题，或一句要判断的错话** —— `front :: back :: kind`（kind 可省；取 `trap`、`name`、`date`、`species`、`fact`）：_

- _一个我可能相信的、说得通的错说法？——它站得住吗？ :: **站不住** —— 以及原因，一两句话。_ :: trap
- _一个答案简短、可核对的问题。_ :: _答案。_
- _一种要分辨的物种。_ :: _用于分辨它的特征，以及它会与之混淆的近似种——只写一个名字会被拒绝。_ :: species

_**一张填空卡（cloze）** —— 一句真话里挖掉一个词。把 `{{c1::…}}` 套在那个词上，它就会进入另一种笔记类型。它的 kind 是必填的，中间可以放一条提醒：`句子 :: 提醒 :: kind`。Anki 会为每个 `{{cN::}}` 生成**一张卡**，所以两个空就是两张卡——只有当这两件事确实彼此独立时才值得，因为每个空都会出现在另一张卡的正面。_

- _秦始皇于 {{c1::公元前 221 年}}统一中国。_ :: date
- _{{c1::格拉西一世}}于 494 年向阿纳斯塔修斯提出双权之分。_ :: _比查士丁尼早四十年；最先提出这一主张的是拉丁西方。_ :: name

**而下面这些根本不写在这里。** **推导** —— “为什么必然如此” —— 因为卡片把重建变成辨认，而 `reviewing` 技能明确说那比不复习更糟；它们留在 [[复习队列]] 上。**填空式的 trap 直接被拒绝**：要判断的一句话必须完整写出。而一张“事实”卡上硬接一个 *为什么*，就是一张贴着事实标签的推导——如果答案是一句推理，它属于队列。

_凡是不符合上述形状的，都会被拒绝，而不是被悄悄拆错。_
