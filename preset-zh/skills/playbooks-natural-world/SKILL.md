# 自然世界打法

这些学科有真正的规律，这让根基比人文学科容易——但它们有自己的两个陷阱：**尺度**（那些数字在人类直觉之外，于是学习者的直觉悄悄换上了某个错误的东西）和**命名**（名字看起来像事实，实则是不断在变的约定）。

## 生命科学

**整个领域的无条件真理是：生物通过共同祖先而彼此相关**，其他一切都在这条的下游：为什么会有同源结构、为什么分类是一棵树、为什么物种具有它们具有的性状、为什么没有“高等”与“低等”。把这条作为根来教，生物学的大部分就变得可推导，而不是一列生物。它的推论同样承重：**变异是原料，选择是分拣，而两者都没有目的。**

然后是那套可复用的结构：组织层次（分子 → 细胞 → 组织 → 个体 → 种群 → 生态系统 → 生物圈），以及每个层次让什么变得可见、是它下面那层做不到的；能量的流动（单向，来自太阳，每一步都在降级）与物质的循环（一圈又一圈）相对照——这个对照是生物学里最干净的无条件真理之一，它解释了多得惊人的东西；稳态及其反馈回路；以及一个种群的*增长*与它的*调节*之间的差别。

**系统发生是工具，不是装饰。** 教他们读支序图：节点是共同祖先，分支长度不是“进步”，而一个类群只有包含其祖先的全部后代时才是真实的。一旦他们会读一张，分类学就不再是死记，而变成一场关于证据的论证。真菌比植物更接近动物——这一个对民间分类的更正值得明确地教，因为它重组了大量的假定。

**鉴定是一次带置信度的判定，从来不是一个事实。** 正确的问题不是“这是什么？”，而是“哪些特征把它放在这里，还有什么别的具有这些特征？”教鉴别特征，然后教相似种，然后教检索表。这正是这套方法的检查题发光的地方：给他们一段标本描述，问它沿检索表走到哪一组，以及检索表会在哪里失效。

### 安全——真菌学（不容商量）

真菌是唯一一门讲授错误可能杀死他们的学科。

- **绝不把一次鉴定说成可以安全食用。** 给出判定、鉴别特征、置信度，以及危险的相似种——每一次都要。
- 那些经典混淆就是要明确地、早早地教的：带鹅膏毒肽的*鹅膏属*物种与可食的伞菌和马勃相对；毒鹅膏和毁灭天使与草菇和*蘑菇属*相对；*盔孢伞属*与*裸盖菇属*、以及与蜜环菌相对；*月夜菌属*与鸡油菌相对；*鹿花菌属*与羊肚菌相对。每一对里都有一个把它们分开的*特征*——孢子颜色、菌褶着生方式、菌托、生境、季节——而那个特征才是教学，不是那个判决。
- 教他们“它长得像图里那样”不是鉴定，孢子印和生境是证据，而一个假羊肚菌可以致命。拿不准时，答案就是：不要吃它。
- 教他们去*学会*鉴定，而不是*索要*鉴定：检索表、特征、孢子印、生境、季节，以及当地的采集活动或协会。学习才是要点，而它同时也是安全。

### 植物学

- **先教科的特征**：那些反复出现的组合（伞形科的伞形花序和抱茎叶柄，十字花科的四瓣花和六枚雄蕊，唇形科的方形茎和对生叶，豆科的蝶形花）给了他们一个在他们从没见过的植物上也能用的抓手。科是整个学科里杠杆最高的节点。
- **把词汇作为工具装上，而不是作为术语**：叶的排列、边缘、脉序、着生方式；花序类型；花程式。然后通过让他们*描述*一株他们能看见的植物来检查，精确到你能把它画出来。
- **物候是让它变真实的那一层**：在他们自己的地区，什么出来了、什么时候。绑在他们自己的散步上，这是这门学科的引擎——在野外学会的植物留得住；从清单里学会的植物留不住。
- **陷阱**：把植物教成一间名字的画廊。一个没有鉴别特征的名字是一个会腐烂的事实。名字 → 特征 → 相似种 → 它长在哪里，每一次都这样。

### 生态学

能量流动和养分循环是根；然后是营养级以及它们为什么短；然后是演替；然后是那两个重组一切的想法——种群受密度制约和密度无关两类力量调节，以及“自然平衡”是一个故事而不是一个发现（扰动是正常的，群落是偶变的）。预期那些神话：原始荒野、狼当英雄、整齐的食物链。

## 地球科学

**根基是深时加上作为方法的均变论**：我们看得见的同样那些物理过程，作用在他们感觉不到的跨度上。这两样合起来让几乎其他一切变得可推导，而它们恰恰是直觉拒绝的东西——这就是为什么第一件工作是用一个学习者能感觉到的尺度去打破直觉（一米的纸带上的一年；一个人的一生是地质柱上的一根发丝那么宽）。

然后是可复用的结构性真理，按依赖顺序：

1. **岩石循环和三大岩类**，作为一个过程的循环，而不是标本的分类。
2. **板块构造**，作为统一理论：边界类型以及各自产出什么（新地壳、被毁的地壳、滑动的地壳），从一个机制解释了造山带、地震、火山、洋盆和大陆的形状。把矿物和岩石鉴定折进它里面，不要分开教。
3. **地层学原则**——叠覆律、原始水平律、切割关系、包裹体、生物层序律——它们是这门学科版本的逻辑：从它们出发，一串事件是*可推导的*。这是整个学科里最适合“我当初怎么可能发现这件事”的地方。
4. **速率及其方法**：放射性测年、它的误差范围、每种同位素适合什么，以及一次测量和一次模型输出之间的差别。绝不在没有背后方法的情况下给出一个日期。

**地理学是那座桥，值得自己的一块。** 自然地理是人的尺度上的地球科学——地貌、水系、气候、土壤、生物群区——而它是他们会在散步中用上那门科学的一层。人文地理是另一半：人口、聚落、资源，以及这样一个事实：**空间与地方是不同的研究对象**，每一张地图都是一个带投影和目的的论证，而边界和区域是被造出来的，不是被找到的。地理学里最有用的一个教学动作是一张有故事的地图：把同一个地方放进两种投影或两个世纪，问什么变了、为什么。

## 横向：这些学科怎样才教得好

- **核实名字、日期和当前分类**，用 `subagent_researcher`。分类学在动、分布区在变，而这个领域的词汇恰恰是语言模型会编造的那类细节。给出你遵循的权威。
- **图在这里不断挣得位置**：岩石循环、一张支序图、一个剖面、一张食物网、一根地质柱、一条深时时间线、一个流域、一张气候图。这是 `subagent_diagram_maker` 会被用得最多的学科家族。
- **野外的知识胜过清单上的知识。** 只要可能，就把材料绑到学习者周围的东西上——他们自己散步路上的植物、他们自己郡县底下的岩石、他们看得见的天气。问他们注意到了什么；那既是探测，也是动机。
- **尺度检查是这些领域里价值最高的检查题**：“如果这条时间线是一米，第一个人在哪里？”“那个速率要多久才能移动那么多？”“哪个更大——物种的数量还是恒星的数量？”答错一个，直觉就是缺的；答对，那些数字才开始意味着什么。
