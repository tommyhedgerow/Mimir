# 学一门语言

这是唯一一门目标完全不是理解的学科。目标是**自动产出**：认识一个词意味着能在用得上它的时间里把它提取出来，而掌握一条规则意味着不查它就能用它。理解在这里是必要的，而且远远不够——所以这套方法的两条原则在这里用法不同。

**这门学科的无条件真理**——不多，但确实无例外，而且值得明确教给他们，因为它们解释了下面每一条为什么有效：

1. **语言是通过理解讯息获得的，不是通过研究规则。** 每一个小时的可理解输入都比一个小时的语法表格做得更多；语法让输入更快，它不替代输入。
2. **是提取，不是复习，建起记忆。** 再读一遍清单产出的是熟悉感；回想它产出的才是可取用性。只有后者能活到他们需要它的那一刻。
3. **频率极不平均。** 最初一千个词承载了日常口语和文本的压倒性多数。他们学哪些词，比学多少个更重要。
4. **在罗曼语族里，音变是规则的**——这就是为什么同源词便宜，也是为什么一个看起来毫无关系的词通常并非如此，一旦你知道那条对应关系。

## 一次会话是什么样

探测 → 计划 → 讲授这个形状成立，但各阶段是：**他们在每条线索上处在什么水平**（词汇量、听力、产出、文字、语法范围）——要真的试一次，不是自我报告——然后是**那条弧线**，然后是循环。测他们的水平意味着请他们*产出*：说点什么、朗读点什么、把一个句子双向翻译、听写一个短语。学习者会系统性地高估自己的水平，而边缘只有靠尝试才能找到。

节点循环，改写后：

- **词汇**：直接解锁这件工具，因为它就是一件工具：复习队列里的一张卡片。最初一千个条目要**按频率顺序、在语境里、在短语里**教——一个在短语里学会的词免费带着它的语法，而一个从清单里学的光秃秃的词，是一个他们放不进句子的词。
- **语法**：作为一个**他们已经能看见的模式**，然后才给它一个名字。拿一个他们理解的句子，改动一处，问什么变了。规则是他们已经遇见过的模式的压缩，不是遇见它们的前提条件。先于任何输入去教那张陈旧的时态序列表，就是行不通的典型。
- **发音**：身体的、立刻的、出声的。有真实反馈的最小对立对，以及他们那些语言特有的陷阱——法语和葡萄牙语的鼻化元音、日语的拍节时长和音高重音、普通话的声调和变调、威尔士语改变词*开头*的辅音交替、西班牙语和意大利语的元音纯度和叠辅音。声调和辅音交替不是高级话题；早早没学会，它们要花掉好几年。
- **文字**：对日语和普通话来说这是它自己的一条线索，有它自己的提取队列。假名先练到不假思索；汉字按部件、按部首，在它们出现的词里学，手写一次。一个孤立地学的字是一幅画；在一个词里，它是一个词。
- **听力**：用略高于他们水平的材料，反复听，先带文本再不带文本。跟读——跟着录音朗读——是节奏和产出上单产最高的练习，而且它可测量，这使它成为一道好的检查。
- **口语**：早说、说得很糟、经常说。错误是数据。更正是**重铸式**的——自然地回答，用上更正后的形式，而不是插进一条规则打断他们——除非那个错误正在固化，那种情况下直接点它一次。

## 复习队列干重活

在这门学科里，复习不是维护步骤；它是主引擎。上面的一切都取决于在扩大的间隔上提取，所以：

- **词汇和文字作为它们自己的条目进 `Learn/Reviews/`**，有它们自己的间隔，与概念复习分开，因为它们是几百个条目而不是几十个。
- **卡片必须要求产出，不是再认。** 目标语言进来，意思出去；然后反过来——意思进来，目标语言出去——那才是真正要紧的方向，也是学习者会跳过的方向。尽可能用句子，不用孤立的词：从一个他们已经见过的句子里挖空一个词。
- **只有在他们不会把它们搞混时才交错语言。** 对一个罗曼语族集群的学习者，法语/意大利语/西班牙语/葡萄牙语会互相污染；这个代价是真的，值得直说，也值得按会话、按标签把它们分开。
- **Anki 可用。** 他们已经在库外维护着一套 Anki 卡组。主动提出按 Anki 插件期待的形式输出卡片（一个 `START` … `END` 块，带 `Front:` / `Back:` 字段），让队列可以被导出而不是被重复；库内复习仍然是默认，因为它只差一次点击，也不需要别的什么东西在跑。

## 为一门语言规划一条弧线

一门语言的课程规划沿着几条独立推进的线索走：**词汇量**（可测量：数队列里的条目）、**听力**（可测量：他们能跟上什么）、**产出**（可测量：他们能说多久才卡住）、**文字**（可计数）、**语法范围**、**发音**（具体的陷阱，一个一个关掉）。把弧线设在这些线索上，而不是设在某本教材的章节上，并用 `subagent_cartographer` 摸清这门具体语言的结构——它真正难的部分各不相同（威尔士语的辅音交替、日语的敬语层级、普通话的体标记、法语的联诵），而知道哪些是承重的，正是让计划诚实的东西。

进展是慢的、非线性的，而且在很长时间里感觉像失败。一开始就说出来，然后给他们看那些证明它并非失败的测量：词汇计数、三个月前的一段录音、一个他们现在能读的段落。在这门学科里，学习者自己的感知是手边最不可靠的仪器，这使库里的记录格外有价值。

也加载 `playbooks-humanities` 技能，用于一门语言的*文化*那一面——它的历史、它的文学、它的名字、它从哪里来——那是另一项工作，遵循那套规则。
